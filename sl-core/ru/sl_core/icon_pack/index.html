    Набор иконок

    Загружайте и повторно используйте SVG-иконки на страницах вашего сайта.

    Возможности

    • Загрузка SVG-иконок в единый SVG-спрайт.
    • Изменение палитры и персонализация цветов иконки под стиль сайта.
    • Система цветовых групп через SCSS-переменные для динамической интеграции цвета со стилями и темами SL.
    • Использование иконок в любом месте с помощью коротких SVG-ссылок вместо встраивания объёмного SVG-кода.
    • Вставка иконок напрямую из CKEditor с помощью кастомного выпадающего списка (плагина).

    Листинг

    Страница со списком всех загруженных SVG-иконок доступна по ссылке из меню (если включена) или по ссылке на странице конфигурации расширения. Состоит из:

    1. Таблица с перечнем загруженных в спрайт иконок
    2. Элементы управления, включая пользовательскую конфигурацию отображаемых колонок
    3. Фильтрация списка иконок

    Добавление иконки

    Пример

    В качестве примера добавим иконку телефона. В дальнейшем эта иконка будет использоваться в тексте модуля

    Для перехода на страницу добавления иконки нажмите кнопку [ Добавить ]

    Откроется страница с формой, поля которой необходимо заполнить:

    Название - поле может содержать произвольный текст и необходимо только для удобства поиска и идентификации иконки в списке

    Ключ иконки - поле должно содержать уникальный идентификатор иконки.

    Загрузка иконки

    SVG-изображение - поле загрузки файла svg изображения. Нажмите кнопку [ Загрузить ], в открывшемся окне проводника выберите файл иконки в формате *.svg. Предварительно скачать SVG файл можно с любого доступного банка SVG изображений, например svgrepo.com

    После загрузки файла его изображение и палитра отобразятся на странице

    Палитра и категории

    Любой цвет можно изменить что сразу отобразится на иконке в поле предпросмотра

    Каждому цвету автоматически назначена одна из категорий

    • Основной цвет
    • Второстепенный цвет
    • Третичный цвет
    • Дополнительный цвет-X

    Первые три категории делают возможным изменять цвет иконки динамически согласно теме оформления сайта (если предусмотрено) или позволит управлять цветом через родительский элемент после применения к нему пресета стилей в редакторе CKEditor который используется в OpenCart как редактор текстов по умолчанию.

    По примеру

    Как видно, после загрузки иконки синий цвет остался без "управляемой" категории, присвоим ему категорию Основной цвет. Категории не могут повторяться. Если назначить категорию другому цвету, она автоматически поменяется местами с категорией выбранного цвета.

    Также, для примера, немного изменим цвета

    Кнопка [ Обьединить выбранные заливки в одну категорию с общим цветом ] нужна для того, чтобы объединять похожие цвета в одну группу, что облегчает их дальнейшее динамическое изменение.

    Размер

    Ширина и Высота - поля, отвечающие за размер иконки на странице.

    Задать размер можно в разных единицах:

    • В абсолютных единицах измерения, пикселях (px)
    • В единицах, зависящих от текущего размера текста (em)
    • В единицах, зависящих от размера корневого шрифта (rem)
    • В процентах (%)

    Если не указывать размер, по умолчанию он будет равен 2rem

    Для сохранения заполненной формы нажмите кнопку в верхней части страницы справа

    • [ Добавить ] при добавлении
    • [ Сохранить ] при редактированиии иконки.

    Иконка будет добавлена в SVG-спрайт и отобразится в листинге на основной странице расширения.

    Внимание

    Последующее редактирование размеров иконки не повлияет на размер её копий, которые уже были добавлены в текст через редактор CKEditor. Их высота и ширина фиксируются в момент вставки.

    Использование иконки в тексте на примере можно посмотреть по ссылке где создается простой тесктовый модуль для вывода в шапку сайта.

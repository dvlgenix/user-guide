    Добавление текстового модуля

    C помощью модуля из стандартного набора OpenCart будет создан текстовый модуль для отображения акционной информации и контактов в шапке сайта.

    Рекомендуется переходить к этому разделу после того, как были созданы иконка, пресет стилей и новый блок макета, то есть после изучения разделов по добавлению:

    SVG иконки, Пресета стилей и Блока макета

    Настройки расширений SL Core

    Также необходимо убедиться в том что плагин для редактора CKEditor включен в настройках расширений SL Core, а также включен статус самих расширений для отображения стилей и иконок на фронтенде сайта:

    1. Пресеты стилей
    2. Набор иконок

    Создание модуля

    Для добавления текстового модуля:

    1. Перейти в раздел меню Расширения (Extensions)
    2. Перейти на страницу одноименного подпункта Расширения (Extensions)
    3. Выбрать Модули (Modules) из выпадающего списка
    4. Найти в списке модуль HTML Content, нажать кнопку Установить (Install), если модуль не установлен

    Если модуль уже установлен, нажать на кнопку Редактировать (Edit) или, если модули уже добавлялись, Добавить новое (Add new).

    Откроется страница с формой добавления модуля и следующими полями:

    Название модуля - название которое будет отображаться в списке всех доступных модулей при добавлении в макет

    Ниже расположена вкладка с контентом для установленного языка сайта. Если сайт мультиязычен, необходимо заполнить каждую языковую вкладку.

    Заголовок - в данном примере не нужен, заполнять не надо

    Текст - текст который будет виден на сайте

    Статус - включить обязательно, иначе модуль не отобразится на сайте даже если будет добавлен в макет.

    Кроме полей формы в самом редакторе также должны появиться два выпадающих списка:

    1. Текущий стиль текста со списком всех доступных пресетов стилей
    2. Список загруженных SVG иконок

    Применение пресета стилей

    После того, как текст добавлен в окно редактора, выделите его часть с помощью мышки и, не снимая выделения, выберите из списка пресетов стилей стиль Phone number, который был создан ранее.

    Выбранный стиль применится к тексту

    Добавление в текст иконки

    Иконку можно вставить в любое место, установив курсор и выбрав иконку из списка, но, так как пресет стиля содержит цветовые настройки которые могут применяться к дочерним элементам, имеет смысл вставить иконку "внутрь" текста к которому применялся стиль.

    Цвета иконки подстроятся под цвета, заданные в пресете стилей, и при необходимости будут меняться при наведении мышкой.

    В сравнении со встроенными в редактор возможностями стилизации текста, данный способ не требует постоянного подбора параметров шрифта, цвета и не замусоривает исходную разметку inline-стилями

    После внесения всех изменений необходимо нажать на кнопку [ Сохранить ] в правом верхнем углу страницы.

    Модуль создан. Осталось вывести его в нужной позиции недавно созданного блока макета.

    Вывод модуля на сайте

    Для добавления текстового модуля в блок макета:

    1. Перейти в раздел меню SL Расширения (SL Extensions)
    2. Перейти в под-раздел меню Дизайн (Design)
    3. Перейти на страницу списка всех созданных блоков Блоки макетов (Layout blocks)
    4. Найти блок макета куда будет добавлен модуль и нажать кнопку [ Редактировать ]

    Дальше

    1. Открыть вкладку Модули блока в макетах
    2. Выбрать Макет где именно будет выводиться блок и его модули
    3. Нажать кнопку Добавить

    На страницу добавится вкладка конкретного макета, которая будет содержать список всех закрепленных за редактируемым блоком модулей.

    Сейчас таблица пустая и осталось добавить в нее созданный модуль, для этого:

    • Нажать кнопку [ Добавить ] в правой нижней части таблицы

    • В открывшемся окне выбрать модуль из списка

    • Нажать кнопку [ Применить ] после чего модуль появится в таблице
    • Сохранить конфигурацию блока макета, нажав кнопку [ Сохранить ] в правом верхнем углу страницы

    После этого перейти на главную страницу сайта и убедиться, что необходимая информация выведена в нужном месте.

    Внимание

    Если текст не выводится, еще раз убедитесь в том что сам модуль, блок макета и расширение имеют включенный статус в их конфигурациях.

    Также при наличии систем кеширования страниц, убедитесь что кеш очищен.

    Adding a Text Module

    Using a module from the standard OpenCart set, a text module will be created to display promotional information and contacts in the website header.

    It is recommended to proceed to this section after the icon, style preset, and new layout block have been created, that is, after studying the sections on adding:

    SVG Icon, Style Preset and Layout Block

    SL Core Extension Settings

    You should also make sure that the CKEditor editor plugin is enabled in the SL Core extension settings, and that the status of the extensions themselves is enabled to display styles and icons on the website frontend:

    1. Style Presets
    2. Icon Pack

    Creating the Module

    To add a text module:

    1. Go to the Extensions menu section
    2. Go to the page of the Extensions submenu with the same name
    3. Select Modules from the dropdown list
    4. Find the HTML Content module in the list, click the Install button if the module is not installed

    If the module is already installed, click the Edit button or, if modules have already been added, Add new.

    A page with the module creation form will open with the following fields:

    Module Name - the name that will be displayed in the list of all available modules when adding it to a layout

    Below is a tab with content for the installed website language. If the website is multilingual, each language tab must be filled in.

    Title - not required in this example, leave it empty

    Text - the text that will be visible on the website

    Status - must be enabled, otherwise the module will not be displayed on the website even if it is added to a layout.

    In addition to the form fields, two dropdown lists should also appear in the editor itself:

    1. Current text style with a list of all available style presets
    2. List of uploaded SVG icons

    Applying a Style Preset

    After the text has been added to the editor window, select part of it with the mouse and, without removing the selection, choose the Phone number style from the list of style presets that was created earlier.

    The selected style will be applied to the text.

    Adding an Icon to the Text

    An icon can be inserted anywhere by placing the cursor and selecting an icon from the list, but since the style preset contains color settings that can be applied to child elements, it makes sense to insert the icon "inside" the text to which the style was applied.

    The icon colors will adapt to the colors defined in the style preset and, if necessary, will change when hovering the mouse over them.

    Compared to the text styling capabilities built into the editor, this method does not require constantly selecting font parameters or colors, and it does not clutter the source markup with inline styles.

    After making all changes, click the [ Save ] button in the upper-right corner of the page.

    The module has been created. All that remains is to display it in the required position of the recently created layout block.

    Displaying the Module on the Website

    To add the text module to a layout block:

    1. Go to the SL Extensions (SL Extensions) menu section
    2. Go to the Design (Design) submenu
    3. Go to the page listing all created Layout blocks (Layout blocks)
    4. Find the layout block where the module will be added and click the [ Edit ] button

    Next

    1. Open the Block modules in layouts tab
    2. Select the Layout where the block and its modules will be displayed
    3. Click the Add button

    A tab for the specific layout will be added to the page, containing a list of all modules assigned to the block being edited.

    The table is currently empty, and the created module needs to be added to it. To do this:

    • Click the [ Add ] button in the lower-right part of the table

    • In the window that opens, select the module from the list

    • Click the [ Apply ] button, after which the module will appear in the table
    • Save the layout block configuration by clicking the [ Save ] button in the upper-right corner of the page

    After that, go to the website homepage and make sure that the required information is displayed in the correct location.

    Warning

    If the text is not displayed, make sure once again that the module, layout block, and extension all have an enabled status in their configurations.

    Also, if page caching systems are present, make sure that the cache has been cleared.

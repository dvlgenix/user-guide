    Menu Manager

    The page is accessible from the administration panel menu after enabling the corresponding option in the extension settings, as well as through a link directly from the extension's main configuration page.

    In addition to duplicating the standard functionality for adding modules from the OpenCart administration panel, the page provides convenient search and filtering tools for existing menu modules.

    Features

    All menu module creation, editing, and deletion operations can also be performed in the standard OpenCart section. To do this:

    1. Open the Extensions menu.
    2. Navigate to the Extensions submenu page.
    3. Select Modules from the dropdown list.
    4. Find the SL Menu extension in the list. All added modules will be displayed below as a list with the corresponding edit and delete buttons, as shown in the example below.

    The Menu Manager page provides a more convenient interface for performing these operations. It consists of:

    1. A table listing all created menus.
    2. Controls, including custom configuration of the displayed columns.
    3. Filtering tools for the list of menu modules.

    Adding a New Menu Module

    To open the page for adding a new menu module, click [ Add ].

    A page will open where you only need to enter the new menu name and click [ Create ].

    Selecting a menu type at this stage is optional. The menu name is not displayed on the website and is used only to identify the menu module in the list on administration panel pages.

    After saving, the menu module page will open on the main | Structure | tab. In addition to adding a new menu item using the corresponding button, 4 options for importing a ready-made menu structure in one click are available:

    1. Import Product Categories.
    2. Import Information Pages.
    3. Import Manufacturers.
    4. Import Blog Categories.

    In addition to their names, some newly created menu items can inherit text or an image from the imported resource, such as the text and image of a product category.

    Adding a Menu Item

    Adding and editing a menu item is performed on a separate page consisting of four tabs.

    • | Link | - specifies the menu link type and the resource to which it is associated.
    • | Configuration | - contains the status, display settings, and link attributes.
    • | Style | - allows customization of the link appearance, style, and icon.
    • | Additional | - allows images, text, and banners to be attached. Their display depends on the link nesting level and the menu type.

    Link

    Available resource types are presented as vertical tabs. Selecting a tab sets the active resource type for the link, indicated by a check mark to the left of its name.

    | Custom Link | - differs from the other types by allowing a menu link name and URL to be specified without associating it with a particular resource.

    Other link types associate a menu item with a specific resource. This helps keep page URLs and names up to date, regardless of changes made to the website.

    Name synchronization can be disabled when necessary. In this case, the menu item will have a unique name specified by the user.

    To create such a menu item:

    1. Select the link resource from the dropdown list. The name and URL fields will be filled in automatically.
    2. If necessary, specify a custom menu item name when synchronization is disabled.
    3. Click [ Save ].

    Configuration

    This tab contains settings that affect the menu item currently being edited. The form looks as follows:

    Status - show or hide the menu item.

    Parent Item - move the menu item and all its child items under the selected menu item, making the latter their parent.

    Sort Order - specify the display order of menu items within the same parent item.

    Store - restrict the menu item display to a specific store.

    Manufacturer Pages - restrict the menu item display to manufacturer pages.

    Customer - restrict the menu item display to guests or logged-in visitors.

    Link Target Attribute - specify the corresponding target attribute for the menu item's <a> link element.

    Link Rel Attribute - specify the corresponding rel attribute for the menu item's <a> link element.

    Additional

    Depending on the menu type and appearance, some menu items can display additional information alongside their child items, such as descriptive text, a random linked banner, or a preview image.

    Editing a Menu Module

    Structure

    After adding menu items, the | Structure | tab displays the entire module content as a menu item tree. From this view, menu items can be edited, deleted, or hidden individually or in groups. Their display order on the website can also be changed.

    The main interface elements are:

    1. The search field allows menu items to be found by name. Search does NOT work as a filter: all menu items remain visible. The item matching the search query is marked with a check mark, and its parent tree is automatically expanded.

    2. Menu tree controls are used to perform group operations:

      • a dropdown list of available operations for the selected items;
      • an add button for creating a new menu item;
      • a delete button for removing selected items;
      • a reset button for discarding all unsaved changes.

    3. The menu item tree allows all menu items and nested elements to be viewed. Groups of elements can be selected using the checkboxes to the left of their names, while an individual element can be selected by clicking its row. Selecte menu item can be dragged and dropped to change their sort order within the same parent item. Clicking the visibility icon on the right side of a row enables or disables the item's display on the website.

    4. Clicking a menu item row displays brief information about that item on the right.

    5. The brief information panel allows groups of items of a specific type to be imported as child items, or an individual child item to be added.

    6. To save changes, click [ Save ].

    Configuration

    In addition to the module name specified during creation and the ability to enable or disable menu display on website pages using the Status setting, this tab contains the Placement section.

    The section contains a table that allows the module to be placed in both standard template positions and Layout Block positions. Layout Blocks are added through the corresponding Layout Blocks section included in SL Core.

    To add the menu to any position in any layout:

    1. Click [Добавить] in the bottom-right corner of the table.
    2. Complete the form by selecting the Layout and Position.
    3. Click [Применить].

    After the menu module is saved, it will be displayed on the website in the specified positions.

    Detailed instructions on adding Layout Blocks to the required website positions and placing modules in those positions are available via the link

    Style

    This tab integrates the Style Presets module from SL Core, allowing an interactive style to be assigned to a group of menu items at a specified nesting level.

    The table works similarly to the one described above. To add a style, click [Добавить] in the bottom-right corner of the table and complete the popup form by selecting the style preset and the menu item nesting level to which the style will apply.

    Menu Appearance

    This tab controls how the menu looks on the website, how it responds to user actions, and how it behaves on smaller mobile device screens.

    5+ menu types are available for display on the website. Each type will be covered separately using an example of how the menu appears on the website.

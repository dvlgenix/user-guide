    Блоки макетов

    Создавайте неограниченное количество кастомных блоков макета, размещайте их в любом месте на страницах вашего сайта и выводите в этих позициях любой контент или модули OpenCart.

    Возможности

    • Создание неограниченного количества блоков макета со структурой до 4 колонок.
    • Вывод блоков в любом месте на сайте. Размещение из админ-панели ограничено только доступными к выбору шаблонами и их элементами (HTML-тегами).
    • Настройка индивидуальной ширины колонок для компьютеров, планшетов и мобильных устройств.
    • Привязка любого модуля к любой колонке созданного блока и макету.

    Листинг

    Страница со списком всех созданных блоков доступна по ссылке из меню, если оно включено, или по ссылке на странице конфигурации расширения. Состоит из:

    1. Таблица с перечнем созданных блоков
    2. Пользовательская конфигурация отображаемых колонок
    3. Фильтрация списка блоков

    Добавление нового блока

    Пример

    В качестве примера добавим блок под вывод модуля с информацией над шапкой сайта на главной странице.

    Сам модуль создадим и добавим в этот блок позже в последнем разделе документа.

    Для перехода на страницу создания нового блока нажмите кнопку [ Добавить ]

    Откроется страница, состоящая из двух вкладок:

    1. Основная конфигурация блока, его вид и размещение
    2. Наполнение блока модулями сайта

    Конфигурация

    На этом шаге необходимо заполнить поля формы

    Название - поле может содержать произвольный текст и необходимо только для удобства поиска и идентификации блока в списке.

    Поиск шаблона

    Шаблон - поле с автопоиском, начните вводить путь (route) необходимого шаблона и выберите нужный из списка

    По примеру

    Выбрать common/header т.к. он отвечает за шапку сайта и именно относительно него будет добавлен новый блок

    Основные положения для лучшего понимания:

    1. Каждая страница сайта состоит из отдельных блоков, представляющих собой отрисованный шаблон HTML-разметки.
    2. Шаблон может отображать как крупную часть страницы, так и совсем небольшую.
    3. Вложенность небольших шаблонов в более крупные формирует итоговый вид страницы.
    4. Каждый шаблон, включая шаблоны сторонних тем, имеет собственный путь (route), что позволяет встраивать новые блоки с модулями в его разметку.

    Размещение относительно шаблона

    Размещение - поле определяет, каким образом относительно шаблона будет выводиться новый блок.

    • До шаблона
    • После шаблона

    Соответственно, новый блок будет выводиться до или после всего содержимого шаблона.

    По примеру

    Оба варианта не подходят так как шаблон common/header в отличие от остальных содержит начало разметки каждой страницы сайта в целом, включая корневой тег, и просто добавить свой блок, выбрав вариант до шаблона будет плохой идеей. В случае выбора варианта после шаблона - новый блок будет выводиться после шапки сайта, а именно, сразу после главного меню, что также не подходит по заданной задаче

    Размещение относительно элемента

    Следующие варианты размещения позволят выбрать конкретное место добавления блока

    • До тега
    • После тега
    • Вместо тега

    Соответственно разместить блок до, после целевого тега, либо полностью заменить его.

    При выборе такого типа размещения появится поле где визуально, с помощью мышки, можно выбрать целевой тег среди содержимого шаблона. Выбор никак не меняет содержимое самого шаблона а только помогает расширению получить координаты элемента в файле.

    Не каждый тег доступен к выбору, а только те, у которых в рамках данного шаблона определены начало (открывающий тег) и конец (закрывающий тег). Все "тело" тега станет выделенным, определив его как целевой элемент.

    По примеру

    Укажем целевой тег <nav>, нажав на него левой кнопкой мыши. При этом именно вариант размещения До тега подходит для вывода информации над шапкой сайта.

    На этом шаге форма должна выглядеть следующим образом:

    Оставшиеся варианты размещения:

    • Вручную

    Для использования этого варианта необходимо знать ключ, который получит блок во время своего создания. Ключ можно задать самому либо оставить поле пустым, тогда к зарезервированному префиксу имени ключа добавится число (ID блока).

    Если ни один из вариантов размещения по каким-либо причинам не подошел то, зная ключ, можно вручную вставить его в любом месте шаблона используя любой удобный редактор. Соблюдая синтаксис Twig шаблонов необходимо вставить вывод переменных, как пример: {{sl_block_7}} или {{sl_block_top_line}}

    Контейнер и колонки блока

    Блок макета представляет собой зарезервированное место для вывода модулей, которое также может быть разделено на колонки, в каждую из которых можно вывести модули.

    Одна колонка по своей сути это просто контейнер, две и более колонки формируются на основе Bootstrap классов, стилей и разметки. При этом можно задать адаптивную ширину каждой колонки под разные размеры пользовательских экранов. Для этого потребуется:

    1. Выбрать количество колонок в блоке
    2. Добавить конфигурацию колонок под определенный размер экрана
    3. Задать адаптивную ширину колонок
    4. Нажать кнопку [ Применить ]

    По примеру

    Для реализации задачи необходима одна колонка, это значение выбрано по умолчанию, так и оставить

    Контейнер - по умолчанию каждый блок оборачивается в тег с классом контейнера Bootstrap, но из-за дополнительных отступов это не всегда необходимо, особенно если блок уже выводится внутри подобного контейнера.

    По примеру

    Оставить как есть - включенным. Блок займет место над шапкой сайта и будет отцентрирован на странице как и сама шапка сайта. Если же параметр выключить - блок займет всю ширину страницы, т.е. всё доступное ему место.

    Отступы сетки - по умолчанию включено. Параметр добавляет или убирает отступы между колонками при их наличии.

    Статус - включает либо отключает вывод блока на сайте.

    По примеру

    Включить отображение блока на сайте.

    Для сохранения заполненной формы нажмите кнопку в верхней части страницы справа:

    • [ Добавить ] при создании
    • [ Сохранить ] при редактировании блока

    Блок макета будет сохранён и появится в списке на основной странице расширения.

    Добавление модулей в блок макета

    Для добавления модулей в блок макета:

    1. Перейти на соответствующую вкладку
    2. Выбрать макет, где будут выводиться модули
    3. Нажать кнопку [ Добавить ]

    Добавится вкладка макета с пустой таблицей списка добавленных в него модулей. После добавления модулей в таблицу они будут выводиться в том месте, где расположен сам блок.

    По примеру

    Добавление модуля в блок макета детально показано в последнем разделе документа.

    Для сохранения конфигурации блока макета нажать кнопку справа вверху страницы:

    • [ Добавить ] при создании
    • [ Сохранить ] при редактировании блока

    Совместимость с OCMOD

    OCMOD (OpenCart Modification) - функционал OpenCart, который даёт возможность сторонним расширениям изменять содержимое файлов самого OpenCart. Это может приводить к конфликтам между расширениями и ошибкам в работе сайта, но тем не менее используется многими разработчиками.

    Такие изменения от сторонних расширений затрагивают и содержимое шаблонов на которые могут ссылаться блоки макетов. В большинстве случаев это не должно повлиять на позиционирование блока макета, но 100%-ная совместимость со сторонними расширениями не гарантируется.

    Если блок макета ссылается на файл шаблона, затронутый OCMOD, то изменения блока макета, связанные с Размещением и Целевым элементом шаблона потребуют обязательного обновления модификаторов

    Совместимость с нативным редактором шаблонов

    Функционал расположен в разделе главного меню OpenCart Дизайн (Design), подпункт Редактор темы.

    Редактор темы OpenCart позволяет вносить изменения в разметку шаблона из админ-панели сайта. При этом новое содержимое самого файла сохраняется в базе данных, не изменяя файл на сервере.

    Внимание

    Использовать этот функционал OpenCart не рекомендуется, так как он полностью игнорирует работу OCMOD самого OpenCart и любые изменения в шаблонах через события (events).

    Если окажется, что блок макета ссылается на затронутый редактором файл шаблона, то необходимо вручную проверить, что вывод блока находится в нужном месте шаблона. Редактор использует синтаксис Twig и вывод блока будет иметь вид: {{ sl_block_ + ключ блока }}

    Соответствующее предупреждение добавится внутри формы при редактировании блока макета.

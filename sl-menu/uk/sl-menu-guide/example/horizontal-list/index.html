    Горизонтальне меню (список)

    Цей тип меню може використовуатись для заміни користувацького меню над шапкою сайту, але може використовуватися й у будь-якому іншому відповідному місці.

    Приклад

    Буде показано, як указати тип створеного меню та замінити користувацьке меню над шапкою сайту. Також використовуватимуться заздалегідь завантажені SVG-іконки та раніше створені пресети стилів.

    Докладніше про стилі та іконки можна прочитати в посібнику з розширення SL Core.

    • Набор иконок
    • Пресеты стилей

    Конфігурація

    Налаштування зовнішнього вигляду меню розташовані у вкладці Вигляд модуля меню.

    Серед вертикальних вкладок із типами меню вибрати Горизонтальний список. Ліворуч від назви з’явиться позначка, що підтверджує вибір. Праворуч відкриється форма налаштування вибраного типу меню.

    За прикладом

    Докладний опис створення та наповнення меню наведено в розділі про Менеджер меню. У цьому прикладі посилання створюватимуться вручну з типом ресурсу Системна сторінка, для якого доступний список однойменних сторінок. Також слід звернути увагу на поле Користувач у вкладці | Конфигурация | пункту меню. Воно дає змогу налаштувати відображення пункту меню окремо для зареєстрованих користувачів і звичайних відвідувачів.

    Для реалізації прикладу під час створення нового модуля меню достатньо вказати назву. Посилань небагато, тому всі вони додаватимуться вручну за аналогією з користувацьким меню за замовчуванням.

    Список параметрів:

    • Показувати іконки - якщо для пунктів меню задано іконки, відображати їх ліворуч від назв.
    • Показувати випадаючі списки - відображати випадаючий список, якщо пункт меню має дочірні елементи.

    За прикладом

    Увімкнути. Випадаючий список знадобиться для відображення списку сторінок з особистого кабінету користувача.

    Щоб зберегти зміни, натиснути кнопку [ Сохранить ] у правій верхній частині екрана.

    Розташування

    За прикладом

    Інформація нижче стосується лише реалізації конкретного прикладу меню.

    Оскільки потрібно замінити меню над шапкою сайту, необхідно додати Блок макета - позицію, у якій відображатиметься нове меню.

    Ознайомитися з можливостями блоків макета та докладним посібником із їх додавання можна за посиланням.

    Короткий опис необхідних дій:

    1. Указати назву блока для його ідентифікації у списку. Наприклад, Customer header menu.
    2. Вибрати шаблон "common/header".
    3. Указати тип розміщення замість тегу, оскільки вміст вибраного елемента шаблону буде замінено меню.
    4. У відкритому попередньому перегляді шаблону знайти тег, який відповідає за виведення списку за замовчуванням, і вибрати його.

    1. Вимкнути параметр Контейнер.
    2. Вимкнути параметр Відступи сітки.
    3. Увімкнути параметр Статус.
    4. Перейти у вкладку Модули блока в макетах і додати модуль меню до колонки 1 для Всех макетов.

    Щоб зберегти зміни, натиснути кнопку [ Сохранить ] у правій верхній частині екрана.

    Увага

    На відображення меню впливають одразу кілька параметрів:

    • Статус окремого пункту меню
    • Статус самого меню
    • Статус блока макета (якщо використовується)
    • Статус розширення SL Menu

    Якщо меню не відображається на сайті, переконатися, що всі ці параметри увімкнені.

    Результат

    Після створення меню, додавання модуля до потрібної позиції та налаштування іконок і додаткових зображень меню матиме такий вигляд:

    Меню повністю керується з панелі адміністратора.
